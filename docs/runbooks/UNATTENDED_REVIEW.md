# Unattended independent review and repair

The controller may repeat a fresh independent review after a clear, in-scope
repair when an exact TASK-045 standing grant covers both actions. The loop is
provider-neutral: Codex desktop may connect Bugbot and a repair worker today;
another approved local controller can provide the same typed boundaries later.

The maximum is three repair cycles. A clean result is evidence for the owner,
not approval. Non-repairable findings, malformed tool output, failures,
exhaustion, missing authority, credentials, merges, `main`, deployment and
business/compliance decisions stop for manual attention.
